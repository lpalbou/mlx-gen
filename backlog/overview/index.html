    Backlog Overview¶

    Project summary¶

    MLX-Gen is an independent Apple Silicon image and video generation package derived from mflux. The backlog tracks model integration work, compatibility fixes, release-readiness work, and follow-up investigations that should survive outside chat history.

    Process¶

    • New backlog items must use a unique four-digit global prefix.

    • Model, backend, architecture, task, and quantization resolution must follow ADR 0002: ambiguous or unsupported requests fail closed unless fallback behavior is explicitly requested by the caller.
    • When implementation completes, move the item to docs/backlog/completed/ and append completion evidence instead of deleting the planning history.
    • If a backlog item establishes lasting architecture policy, create or update an ADR before closure.
